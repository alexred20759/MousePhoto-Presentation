# MousePhoto

### Un'esperienza visiva interattiva

MousePhoto è un progetto creativo e sperimentale che trasforma il movimento del mouse in un'esperienza visiva.

Attraverso un cursore interattivo, immagini e contenuti multimediali prendono vita, creando un modo originale di esplorare e vivere la fotografia e la creatività digitale.

L'obiettivo è offrire uno spazio in cui arte, tecnologia e interazione si incontrano, dando vita a un'esperienza diversa dalla tradizionale navigazione web.
